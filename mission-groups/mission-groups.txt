# Mission Groups 2.x 設定檔（UTF-8）。改完存檔，回到船上約 1 秒內生效；任務中改的話，等回船才套用。
#
# 原理：遊戲建立任務組時只把「任務組 ID + 種子」交給大廳，每台機器自己用原版表推出三個任務。
# 所以主機只能決定「用哪一個原版任務組」，不能自己拼任務清單：
# 這裡把一整列原版任務組（含 ID）蓋到遊戲本來會選的那一列，主機建立的就是那個原版任務組，
# 客機不裝 mod 也會推出同樣的任務、目標、變種與地形。
#
# 每段一行：use <任務組列號 0..24>、use id <十六進位 ID>，或 use keep（維持原版）。
#   列號、ID、每個任務組含哪些任務：見 session 日誌資料夾的 mission-groups-catalog.txt。
#   你的星球用的是哪一列：建立任務組後，mod 日誌會寫「operation created: planet …, vanilla row …」。
#
# 區段（遊戲本來要用哪一列時套用；越具體的優先）：
#   [operation <0..24>] 或 [operation id <十六進位>]   那一列
#   [faction terminid]       這個陣營的所有列（= 這個陣營的所有星球；也可寫 automaton、illuminate 或數字）
#   [all]                    所有列
#
# 選項：
#   enabled = 1        0 = 暫時關掉，全部改回原版
#   cross_faction = 0  1 = 允許換成別的陣營的任務組（敵人和星球不搭，可能出錯）
#
# 已經建立的任務組不會變：放棄目前的任務組，或換星球／難度，讓遊戲重新建立。
# 檔案有任何一行寫錯，整份不套用（日誌會寫哪一行），遊戲維持原版。

enabled = 1
cross_faction = 0

# 範例（拿掉行首的 # 才生效）：蟲族星球一律建立第 7 列的任務組。列號以 catalogue 為準。
# [faction terminid]
# use 7
